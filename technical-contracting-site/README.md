# NOVA Technical Contracting — Website

A responsive multi-page static website with a bold construction-photo hero, shared site header/footer, responsive service cards, scroll-reveal animation, mobile navigation, back-to-top interaction, and a quotation enquiry form that opens the visitor's email client.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services overview
- `services/*.html` — Six individual service pages
- `projects.html` — Project gallery template
- `contact.html` — Enquiry form
- `privacy.html`, `terms.html`, `404.html`

## Before publishing
1. Replace the demo brand name, logo letter, and all demo email/domain details.
2. Replace illustrative gallery imagery with company-approved photographs before representing work as completed projects.
3. Update canonical URLs, `sitemap.xml`, and `robots.txt` for the real domain.
4. The enquiry form uses `mailto:info@example.com` as a demonstration. Replace this with a verified email address or connect a real form backend/service for server-side submission.
5. Confirm all services and locations are actually offered by the company.

## Deploy
Upload the contents of this folder to a static host such as Netlify or Hostinger's public web directory. `index.html` should sit at the site root.
